##🇰🇪 Kenya General Election 2018 – Voting Data Analysis (Mock Data)
#📊 Project Overview
This project presents a mock data analysis of the 2018 Kenyan General Election. It leverages Power BI to provide visual insights into voter participation, candidate performance, and geographical patterns across regions and counties.

The primary goal is to explore key election metrics such as voter turnout, vote distribution per candidate, rejected votes, and demographic comparisons.

⚠️ Disclaimer: The data used in this analysis is fictional and for demonstration purposes only. It does not represent real election outcomes.

#🧩 Dataset
File: Large_Kenya_Voting_Analysis.xlsx

Structure: Includes columns such as County, Region, Registered Voters, Votes Cast, Rejected Votes, Population, and vote counts for Candidate A, Candidate B, and Candidate C.

#✅ Questions Answered
#🗳️ Voter Turnout & Participation
Voter turnout by region, county, and constituency — Analyzed using calculated percentages of votes cast vs. registered voters.

Counties with highest/lowest turnout — Highlighted via bar charts and county-level comparison.

Average turnout per region — Computed using DAX aggregations in Power BI.

#👤 Candidate Performance
Top-performing candidate overall — Candidate A received the highest number of votes (2.52M).

Candidate performance per county — Visualized using a matrix and county-wise breakdown.

Region where Candidate B was most popular — Identified through filters and comparative visuals.

#🗺️ Geographic Visualizations
Map highlighting voter turnout per county — Implemented with color-coded fill maps in Power BI.

Heatmap of votes cast vs. registered voters — Used bar and conditional formatting visuals to display performance.

#❌ Rejected Votes
Counties with most rejected votes — Sorted and visualized as part of total votes.

Percentage of rejected votes by region — Derived by calculating the ratio of rejected votes to total votes cast.

#👥 Population vs. Voting
Comparison of population vs. registered voters — Explored with dual-axis visuals.

Correlation between population and votes cast — Briefly examined using scatter plots and ratio analysis.

#📌 Key Insights
National turnout stood at 74.69%, with 6.23M votes cast out of 8.34M registered voters.

Candidate A led the election with 2.52M votes, outperforming others by over 500K votes.

Certain counties exhibited extremely high turnout, while others showed significantly lower participation.

A total of 347K votes were rejected, accounting for a substantial portion of total ballots.

Some counties showed high populations but comparatively lower voter registration, raising questions about civic engagement.

#📎 Tools Used
Power BI: For data modeling, DAX calculations, and dashboard creation.

Microsoft Excel: For mock data entry, preprocessing, and base calculations.

#🧠 Learning Outcomes
This project helped reinforce skills in:

Power BI dashboard creation and interactivity

DAX functions for advanced aggregation

Data storytelling through visuals

Electoral data analysis in a geographical context
